#🎬 TrollFlix

TrollFlix is a visually stunning and interactive web application for discovering movies and TV shows. Designed with modern aesthetics and built using cutting-edge web technologies, it offers a smooth, responsive, and engaging user experience across all devices.

🚀 Features
🔍 Movie & TV Show Discovery – Search and explore trending or top-rated content.

📱 Responsive UI – Optimized for mobile, tablet, and desktop screens.

⚡ Dynamic & Interactive – Intuitive navigation with fluid transitions.

🎨 Modern Aesthetics – Clean, stylish interface for an enjoyable browsing experience.

🛠️ Tech Stack
HTML5 & CSS3 – Structured and styled for a polished look.

JavaScript & TypeScript – Ensuring robust and type-safe code.

React – Modular, component-based UI development.

Redux – Centralized and efficient state management.

🎉 Enjoy exploring TrollFlix!
